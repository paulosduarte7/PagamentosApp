# Changelog

Todas as alterações notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Versioning Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-09-13 - Por Paulo Duarte

### Adicionado
- Importação e leitura de arquivos de comprovantes de pagamento nos formatos PDF, JPG, etc.
- Integração com serviços de Inteligência Artificial para extração automática de dados.
- Persistência e modelagem dos dados de pagamento no MongoDB.
- Endpoints HTTP para consulta de comprovantes e integração com sistemas de gestão financeira.
